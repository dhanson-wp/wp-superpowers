# Default Skills Relationship

WP Superpowers is an add-on pack for established WordPress skills.

Use default skills first when they cover the broad WordPress domain:

- `wordpress-router`
- `wp-project-triage`
- `wp-block-development`
- `wp-block-themes`
- `wp-plugin-development`
- `wp-rest-api`
- `wp-interactivity-api`
- `wp-playground`
- `wp-wpcli-and-ops`
- `wp-performance`
- `wp-phpstan`

Use WP Superpowers when the task needs an add-on workflow above the base domain skill:

- `wp-custom-block-editor` for custom editor composition outside the post editor.
- `wp-admin-dataviews-dataform` for complete DataViews/DataForm admin screens that need full interaction coverage and wp-admin quality gates.
- `wp-plugin-quality-gate` for release-minded plugin review.
- `wp-block-markup` for block markup generation/validation and external MCP integration.
- `wp-playground-verification` for disposable proof flows with screenshots/reports.
- `wp-interactivity-practice-loop` for small verified Interactivity API practice loops.

Do not copy default skills into this repo. Compose with them, reference them, and fill the gaps above them.
