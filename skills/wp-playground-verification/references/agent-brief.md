# Agent Brief: Playground Verification

Use this to prove WordPress work in a disposable environment.

## Default

- Start WordPress Playground.
- Mount the target plugin/theme.
- Activate it.
- Navigate to the target admin or frontend screen.
- Check console output.
- Interact with the feature.
- Capture screenshots or reports for non-trivial UI work.

## Done Means

- WordPress loads.
- The feature activates.
- The target screen works.
- Console is clean or known warnings are documented.
- The final report names exact URLs and checks.
