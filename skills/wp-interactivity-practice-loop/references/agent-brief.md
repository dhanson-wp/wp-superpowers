# Agent Brief: Interactivity API

Use this for frontend-interactive WordPress blocks.

## Default

- Keep the block server-rendered.
- Use `block.json`.
- Use Interactivity API directives for state and actions.
- Keep the example small.
- Verify in Playground or a real WordPress environment.

## Done Means

- Block renders meaningful markup.
- Directives update state correctly.
- Pointer and keyboard interaction work.
- Console is clean.
- Behavior survives reload.
- The implementation feels like WordPress, not a standalone app.
